## Specific correctness repairs

- A frozen Qwen `qwen-0-999` coordinate space was not forwarded by the worker,
  allowing fallback to CSS pixels. The propagation and enum checks are now
  tested. This does not retroactively prove why a historical task failed.
- Lifecycle completion is separate from explicit task completion and native
  success. Provider errors are not promoted to capability evidence.
- Component-level provenance must match the trusted opportunity; adding a
  measured label to an outer envelope cannot promote synthetic components.
- Native evaluation must bind the exact official task/source/evaluation ref.
- HAR is finalized by closing the browser context, then sealed outside the actor
  receipt. It is never supplied as a visual/hybrid observation.
- VWA's 117 intent-only ambiguous cases are resolved by full-content matching,
  not fuzzy matching. Duplicate intent text is not task identity.
- The old Browser Use lock had 107 packages while the actuator environment had
  110. Full-set checks now detect the three unlocked packages. The new private
  profile explicitly binds the existing 110-package actuator lock; no wheel or
  lock file was rewritten to manufacture a pass.

## Remaining gates, in order

1. **Timing semantics:** the current worker caps the entire actor subprocess
   at the task budget, while context initialization/HAR close add overhead and
   the native decision loop starts its own clock. Freeze a common policy for
   setup, decision/action and artifact finalization, enforce the chosen global
   deadline, and test that close/serialization overhead is never silently
   attributed to model incapability. Do not quietly extend only an agent arm.
2. **Host and fixtures:** native Linux x86_64; measured Docker data-root capacity;
   reviewed complete WAV/VWA dependency locks; required official site closure.
   Local x86 VM had about 15 GiB free, below the approximately 76.9 GB compressed
   classifieds image alone. Host free disk is not VM free disk. Existing WAV
   container wildcard host bindings also fail the strict loopback policy.
3. **Full adapters:** complete task-bound reset/cleanup CLI, reset-scoped login,
   reviewed Traditional scripts and replay source snapshots, VWA/ATA native
   evaluator/fixture parity. The generic lifecycle API is not a turnkey adapter.
4. **Measured fixture proof:** all 12 benchmark/profile cells, including mutate/
   restore/isolation and positive/negative/malformed evaluator controls.
5. **Task-level rehearsal:** retain all fixed tasks; run 2 → 10 → 20 and the
   prespecified repeats only after preceding gates. Preserve capability failures
   and quarantine external/engineering failures. New cohort presently has
   **0/360 execution receipts and 0/12 ready fixture cells**.
6. **Sponsor review:** fresh-host installation and API joint acceptance,
   scientific screening/authoring evidence, then separately seal formal
   admission. Historical cloud data are neither needed nor modified here.
